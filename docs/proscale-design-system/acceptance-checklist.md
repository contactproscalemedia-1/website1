# Acceptance Checklist

## Brand and Message

- [ ] The experience feels calm, authoritative, and commercially serious.
- [ ] The visual system follows the black, white, and red only rule.
- [ ] The tone is direct and accountable rather than promotional.

## Design

- [ ] The layout feels editorial and architectural.
- [ ] Typography supports hierarchy and authority.
- [ ] Motion is limited to arrival, departure, and feedback.
- [ ] No decorative ornamentation or generic agency cues appear.

## Engineering

- [ ] The implementation uses the approved stack.
- [ ] Accessibility requirements are met.
- [ ] Performance considerations are addressed.
- [ ] No unsupported dependencies were introduced.

## Content Integrity

- [ ] No fabricated claims, dates, results, budgets, clients, or testimonials are present.
- [ ] The copy supports the business case without exaggeration.
