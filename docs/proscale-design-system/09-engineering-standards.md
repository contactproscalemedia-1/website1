# Engineering Standards

## Stack

- Next.js 15 App Router
- React 18
- TypeScript
- Tailwind CSS v4
- Framer Motion
- pnpm

## Implementation Standards

- No new dependencies without approval
- Accessibility is mandatory
- Performance is part of design
- Preserve unrelated working sections
- Build one room at a time
- Keep code simple, typed, and maintainable

## Quality Expectations

- Use semantic HTML and accessible interaction patterns
- Keep animations lightweight and purposeful
- Avoid unnecessary client components
- Ensure content remains accessible at all viewport sizes
- Do not fabricate business results, clients, testimonials, dates, budgets, or claims
