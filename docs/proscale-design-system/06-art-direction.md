# Art Direction

## Visual Character

The visual language should feel dark, editorial, architectural, and courtroom-like. The result should feel serious and controlled rather than playful or promotional.

## Image Direction

Use still photography or controlled light treatments that suggest structure, tension, and precision. The first choice should be CSS-based light and shadow. A still image is acceptable when it adds texture or narrative value. Video should be used only when it meaningfully contributes to the experience.

## Avoid

- Gradients
- Glows
- Decorative ornaments
- Generic agency visuals
- Stock-style teamwork imagery
- Visual clutter that weakens confidence

## Implementation Notes

Treat imagery as a supporting structure. It should reinforce the message of accountability, precision, and commercial seriousness. Keep the composition elegant and restrained.
