# Layout System

## Grid Approach

Use a structured, asymmetric layout system that feels precise rather than symmetrical. The homepage should be perceived as a sequence of deliberate rooms rather than a single continuous page.

## Spacing Model

Use generous spacing between sections and within content blocks. Negative space is part of the design language and should be treated as a structural element.

## Room Structure

Each room should follow a consistent internal pattern:

- A strong opening statement or heading
- A compact supporting message
- A clear visual anchor
- A defined next action or transition

## Responsive Behavior

- Mobile: prioritize clarity and vertical rhythm
- Tablet: maintain the same editorial hierarchy with slightly more horizontal balance
- Desktop: use wider negative space and stronger asymmetry

## Implementation Notes

Keep the layout readable at all sizes. Avoid crowded layouts, decorative fills, and unnecessary columns. When a section needs emphasis, use scale, spacing, and contrast rather than decoration.
