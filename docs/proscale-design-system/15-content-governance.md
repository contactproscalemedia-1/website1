# Content Governance

## Purpose

Ensure every piece of copy sounds like ProScaleMEDIA.

## Voice

- Calm
- Precise
- Confident
- Evidence-first
- Never arrogant
- Never exaggerated

## Never Use

- Leading
- World-class
- Innovative
- Cutting-edge
- Best
- Revolutionary
- Game-changing
- Disruptive
- Premium quality

Unless objectively proven.

## Prefer

- Evidence
- Systems
- Decisions
- Scale
- Performance
- Measurement
- Growth
- Accountability
- Execution

## Headline Rules

- Maximum: 8 words
- One idea only
- Avoid punctuation unless essential
- Prefer nouns and verbs

## Supporting Copy

- Maximum: 24 words
- One sentence
- Concrete

## CTA Rules

- Maximum: 3 words

Examples:

- Examine the evidence
- See our work
- View case studies
- Book a call

Never:

- Click here
- Learn more
- Start now

## Numbers

Numbers should dominate the visual hierarchy.

Prefer:

- 50+
- $8M
- 4X
- 12 Days

Never write numbers as words unless grammatically required.

## Dates

- Always explicit

Prefer:

- 2026
- Q3 2026

Never:

- Recently
- This year
- Soon

## Currencies

Always use symbols.

Examples:

- $50K
- AED 2.4M

Never:

- Fifty thousand dollars

## Case Study Structure

- Problem
- Decision
- Execution
- Evidence
- Result

Never reverse the order.

## Sentence Rules

- Average: 8–18 words
- Avoid long paragraphs
- Prefer one idea per paragraph

## Formatting Rules

- No exclamation marks
- No emojis
- No decorative punctuation
- No excessive capitalization
- Sentence case for body copy
- Bebas Neue headlines remain uppercase

## Evidence Rules

Never invent:

- clients
- budgets
- timelines
- metrics
- results
- ROI

Only publish verifiable information.

## Accessibility

- Write plain English
- Avoid unnecessary jargon
- Use descriptive link text
- Headings must accurately describe the following content

## Governance Checklist

Before approving copy ask:

- Is it factual?
- Is it measurable?
- Is it concise?
- Does it sound calm?
- Would it still work without adjectives?

If yes, approve.
