# Typography System

## Typefaces

- Bebas Neue: use for monumental headlines, room titles, and major statements
- Inter: use for body copy, nav, labels, forms, metadata, and supporting information

## Type Hierarchy

Use a clear hierarchy that supports authority:

- Monumental headlines for first impression
- Strong but restrained subheads for room framing
- Compact body copy for explanation and proof
- Minimal labels and metadata for clarity

## Rules

- No em dashes
- No exclamation marks
- Use sentence case for most body copy
- Keep uppercase usage controlled and intentional
- Give numbers more visual weight than adjectives

## Implementation Notes

Apply typography as a structural system, not as decoration. Headline scale, letter spacing, and line height should support readability and confidence. Avoid over-styling text with effects or excessive emphasis.
